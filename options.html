AIAssist+ Settings

Configure your API endpoint and keys, or enable Demo Mode for quick judging without credentials.

Tip: If you don't have API credentials for the demo, set Demo Mode to true. The extension will use bundled demo responses so judges can evaluate functionality.
Saved settings are stored locally in Chrome's extension storage (chrome.storage.local).
Need help? Open DevTools on this options page (right-click → Inspect) to view console logs.
